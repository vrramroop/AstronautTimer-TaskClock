# AstronautTimer-TaskClock
A mission clock that allows astronauts to keep track of their tasks on the mission! Completely client-side website so it can be run if you have a web browser and the file downloaded! There are also clear markers in the code so you can edit tasks very easily. 

The versions are in zip files. There is 1 file, the html, and one folder, the image folder. Run the html and it will display the page.
